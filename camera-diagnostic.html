Quick Fixes

  • Close other apps: Zoom, Teams, Skype, Discord, OBS
  • Check Windows Settings: Settings → Privacy → Camera → Allow apps to access camera
  • Check browser permissions: Click lock icon in address bar → Camera → Allow
  • Restart browser: Close ALL browser windows and reopen
  • Update drivers: Device Manager → Cameras → Update driver
